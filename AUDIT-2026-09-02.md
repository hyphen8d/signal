## S1 · `.elevenlabs-key` served over HTTP — **FIXED 2026-09-02**

Was: `curl http://<tailnet-addr>:8080/.elevenlabs-key` returned **200 with the
key**. `serveStatic()` mapped URLs onto the repo ROOT with no filter, and the
systemd unit binds the tailnet; `tools/dev-server.py` was worse while running,
binding every interface. `.gitignore` had kept the key out of git, not out of
HTTP.

Fixed with a static **allowlist** in both servers rather than the dotfile
denylist proposed here — a denylist has to anticipate the next secret's name,
an allowlist does not. Verified live after a unit restart: `.elevenlabs-key`,
`.elevenlabs-voice-id`, `.git/config`, `tools/*.json`, `tests/` and the
servers' own source all 404 over the tailnet, while the app, the dashboard and
`/tools/lib/roster.mjs` still serve. Pinned from both ends in
`tests/admin-server.test.mjs`, and mutation-checked in both directions (too
loose and too tight each turn the test red). Reasoning is in `servable()` and
in CLAUDE.md's admin-backend section.

**This file can now be tracked** — the exposure it documented is closed. Its
durable halves (the perf plan below, the cleared-suspects appendix) are better
off as comments beside the code they govern; see CLAUDE.md's design-record
rule.

## Performance — deferred pending an honest measurement

The frame path is lean (dirty-row tracking verified, no leaks, no per-frame
string rebuilding). The remaining levers are all measure-first, and the
measurement is still owed: a live check was attempted 2026-09-02 via browser
automation, but the tab sat backgrounded (`visibilityState: hidden`, 0 rAF
frames in 2.5s — exactly the covered-window trap CLAUDE.md warns about), and a
number from that state is not a number. **Next session at the machine: open
the deployed site in a foreground window and count rAF over a few seconds.**
Then, only if sustained frame time exceeds ~20ms:

1. **Adaptive quality governor** (`src/crt.js:492-511`) — step `pixelBudget`
   / `superSample` down under sustained slow frames; the composite pass
   dominates and the budget is static today. The single biggest lever.
2. **Skip the spot pass on idle frames** (`src/crt.js:540-547`) — a validity
   flag invalidated on upload/beam/sharpen change saves ~300k px × 14 taps
   per idle frame.
3. **Micro-allocations** (`_runFx` filters, `syntheticAudio()`,
   `gritCurve()`), only if GC pauses are ever actually observed.
